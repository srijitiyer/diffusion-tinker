{\footnotesize\textcolor{hdr}{%
Two seeds per row, full held-out test set (1017 OCR prompts; 320 counting
prompts, 2 samples each). Everything fixed except the regulariser, so
$\beta=0$ is one configuration shared by both families. DDRL rows vary
\texttt{data\_beta}, FlowGRPO rows vary \texttt{kl\_beta}. \textbf{Bold} marks
a change beyond two standard errors. ImageReward was measured by regenerating
each arm on the GPU it was first measured on; the regenerated task reward,
ClipScore and PickScore reproduced the originals exactly, so all four columns
describe the same images. SD3.5 trained 150 epochs, FLUX 80, at roughly 7\% of
the sample budget in the papers. The FLUX panel is withdrawn: with the
3-step SDE window, the replay scored the window's last step at noise level 0,
so its importance ratio underflowed to exactly 0 and a third of the window
contributed no gradient. SD3.5 runs no window and is unaffected. Those arms
are being rerun.%
